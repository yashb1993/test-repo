# PoE2 Mirror-Tier Weapon Crafting Guides

Three crafting routes for making mirror-tier weapons in Path of Exile 2, compiled from community guides (Nov 2026).

| # | Guide | Weapon | Main risk | Rough budget* |
|---|-------|--------|-----------|---------------|
| 1 | [Fractured Phys Crit Bow](01-fractured-phys-crit-bow.md) | Bow (Deadeye / Pathfinder attack builds) | Finishing suffixes + divine spam | 150–400+ div |
| 2 | [Caster Wand / Staff](02-caster-wand.md) | Wand or Staff (spell builds) | First T1 spell-damage prefix | 200–500+ div |
| 3 | [Physical Quarterstaff / Spear](03-phys-melee-quarterstaff.md) | Quarterstaff or Spear (melee) | Hitting 3 phys prefixes together | 150–400+ div |

\*Budgets are rough figures from community guides of different patches. Prices change daily, so check current market prices before you start.

## Read this first

1. **You can't be guaranteed a mirror-tier result.** Every route depends on random rolls. These guides cut down the randomness and tell you when to stop, sell, or change plan, but an unlucky run can still burn your whole budget.
2. **Patch timing matters.** These guides follow the **0.5.x** ("Return of the Ancients") crafting rules. PoE2 **1.0 launches 11 Dec 2026** (per Wikipedia), and crafting may change. Re-check every omen and currency against the patch notes before spending anything.
3. **Making two mirror weapons:** run **Guide 1 or 3 first**. Attack weapons have cleaner prefix pools. Sell your by-products along the way (see "Sellable checkpoints" in each guide) to fund the second craft.
4. **Buy, don't build, where it's cheaper.** Every guide starts from a bought base with one key mod already done (fractured or magic with a T1 mod). Rolling that base yourself is usually more expensive.

## 0.5.x crafting rules these guides rely on

| Tool | What it does (0.5.x) | Notes |
|------|----------------------|-------|
| **Fracturing Orb** | Permanently locks **one random** explicit mod on a rare item with **≥4 mods** | You can't choose which mod. Item can't already be fractured. 20 shards = 1 orb. |
| **Exalted Orb** (Greater/Perfect) | Adds a random mod. Greater/Perfect raise the **minimum modifier level** | Greater min mod level dropped to 44 in 0.5. Use Perfect for top tiers. |
| **Omen of Sinistral / Dextral Exaltation** | Exalt adds **prefix only** / **suffix only** | Core of every route. |
| **Omen of Greater Exaltation** | Exalt adds **two** mods | Use when both open slots are on the side you want. |
| **Omen of Dextral Coronation** | Regal adds **suffix only** | **Sinistral Coronation may no longer drop.** Check in-game. |
| **Chaos Orb + Omen of Whittling** | Removes the mod with the **lowest required item level** (not "worst tier") | Read the mod levels carefully before you use it. |
| **Chaos Orb + Sinistral / Dextral Erasure** | Chaos only removes/rerolls a **prefix** / **suffix** | Expensive (~490–750 ex snapshot). |
| **Orb of Annulment + Sinistral / Dextral Annulment** | Annul only hits **prefixes** / **suffixes** | Fractured mods can't be annulled. |
| **Essences** (incl. Perfect) | Guarantee one specific mod | **0.5: only one crafted mod per item.** Essences, Perfect Essences and Imbued Alloys share that one slot. |
| **Desecration** (bones) | Adds **one** desecrated mod per item. You pick from 3 options | Necromancy omens force prefix/suffix. **Omen of Light** removes only the desecrated mod. **Abyssal Echoes** rerolls the 3 options. |
| **Divine Orb** | Rerolls mod values within their tiers | Last step, often the single biggest cost. |
| **Homogenising omens** | (Old) | Stopped dropping in 0.4. Old stock still works but is scarce. |

## Universal workflow

```
Buy base (ilvl 82+, ideally 85+)  →  lock 1 key T1 mod (fractured / bought)
   →  fill prefixes (Sinistral Exaltation)  →  fix bad prefixes (Sinistral Erasure / Annulment)
   →  fill suffixes (Dextral Exaltation)    →  fix bad suffixes (Dextral Erasure / Annulment)
   →  last slot: Desecration or Essence (only one of each per item)
   →  Divine to top values  →  Mirror
```

**Golden rule:** before every expensive step, write down what you'll do for each possible result, including "stop and sell". Never spend an omen hoping it works out.
